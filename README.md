# Deduction ワイン推理ナビ（Web版）

GitHub Pages で公開するためのファイル一式です。フォルダを使わず、すべて同じ場所に置く構成です。

- `index.html`：アプリ本体
- `apple-touch-icon.png`：iPhone のホーム画面用アイコン
- `icon-192.png`・`icon-512.png`・`icon-maskable-512.png`：Android などのホーム画面用アイコン
- `manifest.webmanifest`：ホーム画面での名前（ワイン推理）とアイコンの指定
- `.nojekyll`：GitHub Pages にファイルをそのまま公開させるための空ファイル
